# Tile Viewer 显微图像浏览器

[English](README.md) | **简体中文**

用来查看 Squid（Cephla）显微镜拍摄的 tile 图像。它可以自动拼接成整张大图，分通道调整颜色和亮度，并导出固定大小或自由大小区域的叠加图。

## 功能
- 打开一次采集的文件夹，也就是里面有 `ome_tiff/` 和 `coordinates.csv` 的那一层。
- 用图像配准拼接所有 tile，不只依赖载物台坐标（坐标可能偏差约 100 像素）。同时做平场校正，去掉每个视野边缘发暗造成的“田字格”。
- 在 napari 里每个通道单独一层，可以分别调颜色、对比度、gamma，也可以开关。可以用 z 滑块看某一层，也可以切换成最大投影。
- 可以水平/垂直翻转、左右旋转 90°，把每张切片调成相同方向再导出。
- 按文件夹记住你的显示设置（对比度、颜色、方向、选框等）。
- 多样本比较：用当前的颜色和对比度打开另一个采集，两个窗口左右并排，可以联动调整；成像条件（曝光、激光强度、增益）不同时会提醒。
- 导出的文件都保存在 `采集文件夹/exports/` 里：
  - **选区**，全分辨率：
    - 固定大小选框：输入宽和高（单位 µm 或像素），拖动调整位置，尺寸锁定不变。
    - 自由矩形选区。
  - **整张大图**，全分辨率。
  - **当前画面截图**。

  选区和整张大图都会保存成带颜色的叠加 PNG（可以加比例尺）。还可以同时保存一份 16-bit TIFF，在 Fiji 里打开就是带颜色的 composite，适合做定量。

## 安装与启动
不需要手动安装任何东西。启动器会用 [uv](https://docs.astral.sh/uv/) 自动下载 Python 和所需软件包，放在一个独立的缓存里，不会影响电脑上已有的 Python 或 conda。

**macOS：** 双击 **`Tile Viewer.command`**。
- 如果提示“无法打开，因为来自身份不明的开发者”：右键点这个文件 → **打开** → **打开**。只需要做一次。
- 如果提示没有执行权限：在终端里运行一次 `chmod +x "/路径/Tile Viewer.command"`。

**Windows：** 双击 **`Tile Viewer (Windows).bat`**。

如果电脑上没有 uv，启动器会先询问，同意后从 astral.sh 安装。
**第一次启动需要下载约 300 MB**，要几分钟，之后启动就很快了。只有第一次启动需要联网。

## 使用
1. 在弹出的对话框里选一个采集文件夹。
   - 第一次打开某个文件夹时会先拼接，12 个 tile 大约 20 秒，进度显示在终端窗口里。
   - 拼接结果缓存在 `采集文件夹/_viewer_cache/`，大小和原始数据差不多。可以随时删除，下次打开会重新生成。
2. **调通道：**
   - 在左侧图层列表选中一个通道，然后在上方的 layer controls 里调：
     - contrast limits：亮度/对比度
     - gamma：曲线
     - colormap：颜色
     - opacity：透明度
   - 点眼睛图标可以开关这个通道。
   - 右侧面板的「自动对比度」可以按当前画面自动调亮度，「重置对比度」则按整张图重新计算。
3. **看某一层或投影：** 用图像下方的 z 滑块选层，或者勾选「最大投影」。
4. **调整方向：** 面板里有「水平翻转」「垂直翻转」「向左/向右旋转 90°」「恢复原始方向」。
   - 已放好的选框会跟着图像一起转，固定框的宽高会自动对调。
   - 导出的 PNG、TIFF 和比例尺都按屏幕上的方向输出，文件名会标出方向（例如 `_flipH-rot90cw`）。
   - 翻转和旋转只改变显示，不复制数据。
5. **固定大小选框：**
   - 输入宽和高，选单位（µm 或像素），点「添加固定大小选框」。
   - 拖动框的内部可以移动它，可以加多个框。
   - 选中一个框按 Delete 删除。
6. **导出：** 点「导出选区」，文件会出现在 `exports/` 里，可以点「打开导出文件夹」直接查看。
   - 导出的颜色和亮度和屏幕上看到的完全一致。
   - 关掉的通道不会出现在叠加图里。

**导出文件名和随文件保存的信息：**
- **文件名**：
  - 「导出文件名」框里默认是 `文件夹名_通道_年月日-时分秒`。显示两个及以上通道时，通道部分是 `merge`；只显示一个通道时，是它的波长，比如 `561nm`。
  - 可以直接改成任意名字，点「默认」恢复自动命名。
  - 多个选区会自动加 `_ROI1`、`_ROI2`，截图加 `_screenshot`。
  - 不会覆盖已有文件，重名时自动加 `_2`、`_3`……
- **图片说明**：每张导出的图片里都写有一段说明，内容包括：
  - 采集名称、导出时间
  - 单层还是最大投影、方向
  - 选区的位置和大小（像素和 µm）、像素尺寸、比例尺长度
  - 每个通道是否显示、颜色、对比度上下限、gamma、透明度、成像参数（曝光、激光强度、增益）
  - 照明校正用的方法

  在哪里看：
  - TIFF：Fiji 里 *Image › Show Info*。
  - PNG：存在 PNG 的 Description / Comment 字段里，可以在「预览」的 *工具 › 显示检查器* 中查看。
- **导出记录表**：同样的信息会追加到 `exports/export_log.csv`，每个文件一行。整理数据或做 PPT 时，可以用 Excel 按样本、通道、对比度筛选和排序。

**用统一的对比度比较样本：** 都在面板的「多样本比较」一栏里。
- **「打开另一个采集（沿用当前颜色和对比度）」**：
  - 在新窗口打开另一个文件夹，各通道的颜色、对比度、gamma、透明度和开关都和当前窗口一样。通道按名称对应。
  - 两个窗口会自动左右并排。笔记本屏幕不够宽时，控制面板会挪到左侧，和 layer controls 叠成两个标签页。
- **「把当前颜色和对比度同步到其他窗口」**：一次性把当前设置复制过去。
- **勾选「联动」**：在这个窗口里的每次调整都会实时同步到其他窗口。
- **成像条件提醒**：如果两次采集的曝光时间、激光强度或增益不同（读取自 `acquisition_channels.yaml`），会弹出提醒。这种情况下，即使对比度相同，亮度也不能直接比较。

**自动保存设置：** 关闭窗口时（以及每次导出后），会把下面这些保存到 `采集文件夹/tile_viewer_settings.json`：
- 各通道的对比度、gamma、颜色、透明度、开关
- 是否最大投影、当前 z 层、方向、画面位置
- 选框和导出选项

下次打开同一个文件夹会自动恢复。打开一个从没打开过的文件夹时，同名通道会沿用你上次的颜色和对比度，同一批样本看起来更一致。想从头开始，删掉这个 JSON 文件即可。

界面语言默认跟随系统语言，也可以在面板最下方切换，重启后生效。

## 拼接是怎么做的，以及怎么判断它成功了
第一次打开一个文件夹时，会依次做下面三步，结果缓存下来，以后打开不用再算。

### 1. 配准：决定每个 tile 放在哪里
- **相邻两块逐对比较**：对每一对相邻 tile，比较它们重叠的那条带，找出精确的错位量。比较用的是所有通道合在一起的最大投影，方法是相位相关。
- **判断是否对上**：两条带的图案吻合得好（相关系数大于 0.3），就算“对上了”。
- **对不上的情况**：通常是空白玻片或信号太弱。由于网格是规则的，这些相邻对就用已对上的那些相邻对的中位错位量。
- **统一求解**：最后把所有相邻对的错位量放在一起求解（最小二乘），得到每个 tile 唯一的位置。

### 2. 照明（平场）校正
显微镜视野中心亮、边缘和四角暗，而且不一定左右、上下对称。照明分布直接从数据里估计：

- **形状**：把很多张 tile 图像各自缩放到相同的平均亮度，取中位数，再用平滑的二维曲面拟合。分别用“被组织完整铺满的图像”和“所有有组织的图像”各估计一次。
- **倾斜**：同一块组织会出现在一个 tile 的右边缘和下一个 tile 的左边缘（上下同理）。它在这两处的亮度比，直接反映了照明左右（或上下）的不对称。程序用所有重叠区拟合出这个倾斜。
- **选择**：从上面几种组合里，选重叠区一致性最好的那一种。具体用了哪种，写在质控图里。

确定照明分布后，每个 tile 先减去相机本底，再除以这个分布。

### 3. 融合
- **重叠区**：两个 tile 的权重都朝各自的边缘逐渐减小，所以接缝处没有硬边。
- **最大投影**：先对每个 tile 单独做投影，再融合。如果先融合再投影，在弱信号数据里接缝会变暗（两张有噪声的图平均后，最大值会变低）。
- **最大投影的噪声偏高**：弱信号时，各层里取最大值本身会被噪声推高。照明校正要除以照明强度，视野边角照明暗，这部分偏高会被额外放大，导致 tile 边角在最大投影里偏亮。程序会把其中一部分噪声偏高当作基底处理、不参与放大，扣多少由数据决定：让最大投影从中心到角落的亮度变化和各层平均一致。信号强的样本里，这个比例会自动接近 0。

### 拼接质控
在面板最上方，配有「查看质控图」按钮和「显示 tile 边界和编号」选项。

- **配准**：
  - 显示有多少对相邻 tile 靠图像内容对上了，以及最终位置和这些测量值相差多少。中位误差不超过 3 像素判为 ✅。
  - 没有任何邻居能对上的 tile，在质控图和 tile 边界上显示为橙色。它们按网格位置放置，对空白区域来说通常没问题，但无法验证。
- **相邻 tile 亮度比**（照明校正的主要检验）：
  - 同一块组织在相邻两个 tile 里，校正后应该一样亮。
  - 亮度比在 0.95–1.05 之间、离散不超过 ±5% 判为 ✅。
  - 同时显示未校正时的数值，方便对比。
- **接缝亮度**：
  - 接缝处的亮度和紧挨着的两侧之比，单层和最大投影各算一个。1 表示看不出接缝。
  - 组织本身的结构在接缝两侧也会变化，所以接缝少于 20 条时只作参考（ℹ️）。
- **校正修不了的情况**：
  - 不同 tile 的对焦深度不同。切片不平整时，同一个 z 层在不同 tile 里拍到的是不同深度。
  - 光漂白。
  - 染色本身的真实差异。

  这些会表现为某个 tile 在某一层里整体偏亮或偏暗；用最大投影看时影响会小一些。

## 说明
- 拼接后的数据经过了平场校正，tile 重叠区也做了融合。严格的定量请回到 `ome_tiff/` 里的原始 tile。
- 通道图层和选区图层都锁定了，不能删除。不锁的话，在图层列表里按 delete 键，napari 会直接删掉选中的图层。要删除某个选框，在图像上点选它，再按 delete 键。
- 只在 macOS（Apple Silicon）上测试过。Windows 启动器还没有实测。

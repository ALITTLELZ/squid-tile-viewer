# Tile Viewer 显微图像浏览器

[English](README.md) | **简体中文**

用来查看 Squid（Cephla）显微镜拍摄的 tile 图像。它可以自动拼接成整张大图，分通道调整颜色和亮度，并导出固定大小或自由大小区域的叠加图。

## 功能
- 打开一次采集的文件夹，也就是里面有 `ome_tiff/` 和 `coordinates.csv` 的那一层。
- 用图像配准拼接所有 tile，不只依赖载物台坐标（坐标可能偏差约 100 像素）。同时做平场校正，去掉每个视野边缘发暗造成的“田字格”。
- 在 napari 里每个通道单独一层，可以分别调颜色、对比度、gamma，也可以开关。可以用 z 滑块看某一层，也可以切换成最大投影。
- 导出的文件都保存在 `采集文件夹/exports/` 里：
  - **选区**，全分辨率：
    - 固定大小选框：输入宽和高（单位 µm 或像素），拖动调整位置，尺寸锁定不变。
    - 自由矩形选区。
  - **整张大图**，全分辨率。
  - **当前画面截图**。

  选区和整张大图都会保存成带颜色的叠加 PNG（可以加比例尺）。还可以同时保存一份 16-bit TIFF，在 Fiji 里打开就是带颜色的 composite，适合做定量。

## 安装与启动
不需要手动安装任何东西。启动器会用 [uv](https://docs.astral.sh/uv/) 自动下载 Python 和所需软件包，放在一个独立的缓存里，不会影响电脑上已有的 Python 或 conda。

**macOS：** 双击 **`Tile Viewer.command`**。
- 如果提示“无法打开，因为来自身份不明的开发者”：右键点这个文件 → **打开** → **打开**。只需要做一次。
- 如果提示没有执行权限：在终端里运行一次 `chmod +x "/路径/Tile Viewer.command"`。

**Windows：** 双击 **`Tile Viewer (Windows).bat`**。

如果电脑上没有 uv，启动器会先询问，同意后从 astral.sh 安装。
**第一次启动需要下载约 300 MB**，要几分钟，之后启动就很快了。只有第一次启动需要联网。

## 使用
1. 在弹出的对话框里选一个采集文件夹。
   - 第一次打开某个文件夹时会先拼接，12 个 tile 大约 20 秒，进度显示在终端窗口里。
   - 拼接结果缓存在 `采集文件夹/_viewer_cache/`，大小和原始数据差不多。可以随时删除，下次打开会重新生成。
2. **调通道：**
   - 在左侧图层列表选中一个通道，然后在上方的 layer controls 里调：
     - contrast limits：亮度/对比度
     - gamma：曲线
     - colormap：颜色
     - opacity：透明度
   - 点眼睛图标可以开关这个通道。
   - 右侧面板的「自动对比度」可以按当前画面自动调亮度，「重置对比度」则按整张图重新计算。
3. **看某一层或投影：** 用图像下方的 z 滑块选层，或者勾选「最大投影」。
4. **固定大小选框：**
   - 输入宽和高，选单位（µm 或像素），点「添加固定大小选框」。
   - 拖动框的内部可以移动它，可以加多个框。
   - 选中一个框按 Delete 删除。
5. **导出：** 点「导出选区」，文件会出现在 `exports/` 里，可以点「打开导出文件夹」直接查看。
   - 导出的颜色和亮度和屏幕上看到的完全一致。
   - 关掉的通道不会出现在叠加图里。

界面语言默认跟随系统语言，也可以在面板最下方切换，重启后生效。

## 说明
- 拼接后的数据经过了平场校正，tile 重叠区也做了融合。严格的定量请回到 `ome_tiff/` 里的原始 tile。
- 只在 macOS（Apple Silicon）上测试过。Windows 启动器还没有实测。
